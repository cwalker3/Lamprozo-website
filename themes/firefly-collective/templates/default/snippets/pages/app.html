WordPress inside. App outside.

Every screen in this app is a real WordPress page — defined in a JSON schema, authored as Gutenberg blocks, deployed by a CLI. The shell around it is a service-worker-backed PWA that pulls each view in over REST. Same source of truth, two surfaces.

Schema + snippets

Pages live in one JSON schema and a folder of Gutenberg HTML snippets. The CLI deploys both into WordPress as real, indexable pages — same content on disk and in the database.

Three editors, one source

Developers edit files. Marketing edits in wp-admin. AI agents drive the CLI. Every change round-trips through the same schema and snippets, so nothing drifts.

App shell + view fetches

This shell loads once. Each view — dashboard, orders, signup — is rendered server-side from its WordPress page and streamed in over REST. The service worker caches it for offline use.
